# Phase 0 report — Reproduce and improve the Kheradpisheh / Ganjtabesh spiking networks

The full Persian report (Word, right-to-left, native equations, figures) is `گزارش_نهایی_فاز_۰.docx` in this
folder; this file is the short English summary required by CLAUDE.md Section 11. All numbers: test accuracy (%),
mean ± std over seeds / folds; every run (config, commit, seed, metrics, figures) is under `work/campaigns/` and
collected in `results_all.csv`; decisions D16–D25 in `DECISIONS.md`.

## Summary
Three papers were reproduced with our own modules (Kheradpisheh 2016 multi-scale STDP; Kheradpisheh 2018 SDNN;
Mozafari 2018 first-spike R-STDP) and improved on two fronts. **Main front (user decision D22): reward-modulated
first-spike decisions with shift-and-add arithmetic only** (the BioVision chip). Second front: SVM/KNN probes.
Caltech reaches the papers on both fronts (RL with our per-neuron calcium adaptive rates: 98.94 ± 0.37 best epoch,
as the paper reports, 98.65 ± 0.49 honest epoch selection; paper 98.9 ± 0.4). MNIST beats SDNN (98.52 ± 0.06 vs
98.4). ETH-80 stays below Mozafari in leave-one-out (84.36 ± 5.31 best epoch vs 89.5 ± 1.9). The hardware
(shift-and-add) mode costs ≤ 1 point. Gate 0 closed by the user on 2026-10-20 ("close Phase 0 and move on").

## Setup
Laptop RTX 3050 (D15); validation-only selection (D17): held-out training objects (ETH-80) or 30 % of the training

## Verification checklist
- S1 features oriented edges / DoG-like, distinct: PASS (run figs).
- C_l decreasing and < 0.01: PASS for conv1 and MNIST conv2; conv2 of ETH-80 stops at the iteration cap (C_l ≈ 0.025).
- Sparsity per S layer in [1 %, 10 %]: conv1 1–2 % PASS; deeper layers 0.1–3 % (below 1 % in ETH-80 conv2).
- Within ~2 points of the papers: Caltech and MNIST with our improvements; ETH-80 gap explained (Section 9-1 / 8-1).

## Red flags observed and how they were handled
Class imbalance in STDP (all Caltech conv2 maps = motorbike) → homeostasis; global-max readout discards location →
grid readout; sparse ETH-80 input → larger image + lower DoG threshold; attention-gated learning silenced the hidden
layer → reward prediction error; R-STDP on sparse conv2 spikes failed → kept the Mozafari single-layer decision.
